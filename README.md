# DastakDo

A single-page, responsive storefront for DastakDo, a modern home and kitchen brand.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. There are no build steps or package dependencies.

## Technology

Semantic HTML, custom responsive CSS, and lightweight vanilla JavaScript. Product photography and optional web fonts load from Unsplash and Google Fonts.

The page includes product search, a responsive navigation menu, add-to-bag feedback, and a live bag count. It is designed to deploy as a static site on GitHub Pages.
